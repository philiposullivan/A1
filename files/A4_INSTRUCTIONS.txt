=============================================================================
WHY OBJECT-ORIENTED PROGRAMMING?
=============================================================================

Objects bundle data and behaviour together, making code:
  - More intuitive (objects mirror real-world concepts)
  - Easier to maintain (changes isolated to classes)
  - More reusable (classes can be used in other projects)
  - Safer (encapsulation prevents accidental data corruption)

Before (dictionaries in A2/A3):
  product = {"name": "Milk", "price": 1.50, "quantity": 20}
  # Anyone can set invalid values:
  product["price"] = -10  # Negative price!
  product["quantity"] = "twenty"  # Wrong type!

After (objects in A4):
  product = Product("P001", "Milk", "Dairy", 1.50, 20, 10)
  product.price = -10  # Raises ValueError: Price cannot be negative
  product.update_stock(-5)  # Validates before updating

STEP 1: Create the Product class (product.py)
=============================================================================

The Product class represents a single product with validation.

File: product.py

REQUIRED ATTRIBUTES (all private):
  - product_id (str) - Unique identifier, read-only
  - name (str) - Product name, validated
  - category (str) - Product category, validated
  - price (float) - Price per unit, must be >= 0
  - quantity (int) - Current stock quantity, must be >= 0
  - min_stock (int) - Minimum stock level, must be >= 0

CONSTRUCTOR REQUIREMENTS:
  - Accept all 6 parameters
  - Use property setters for validated attributes (not direct assignment)
  - This ensures validation happens during initialisation

PROPERTIES (getters) - all attributes need @property decorators:
  - product_id (read-only, no setter)
  - name
  - category
  - price
  - quantity
  - min_stock

PROPERTIES (setters with validation):
  - name: Cannot be empty or only whitespace
  - category: Cannot be empty or only whitespace
  - price: Cannot be negative
  - quantity: Cannot be negative
  - min_stock: Cannot be negative

REQUIRED METHODS:

  update_stock(amount_change)
    - Parameters: amount_change (int) - amount to add (positive) or remove (negative)
    - Raises ValueError if resulting quantity would be negative
    - Updates quantity (private attribute)
  
  get_value()
    - Returns: Total value of the product
  
  is_low_stock()
    - Returns: True if product needs reordering, False otherwise
  
  to_dict()
    - Returns: Dictionary with all attributes EXCEPT product_id
    - Used for JSON storage
  
  from_dict(product_id, data)
    - Class method (@classmethod)
    - Parameters: product_id (str), data (dict)
    - Returns: New Product object
    - Used for loading from JSON
  
  __str__()
    - Returns: Readable string representation of the product
    - Should include: ID, name, category, price, stock levels

STEP 2: Create the Inventory class (inventory.py)
=============================================================================

The Inventory class manages a collection of Product objects.

File: inventory.py

REQUIRED IMPORTS:
  Import the Product class

REQUIRED ATTRIBUTES:
  - _products (dict) - Dictionary mapping product_id to Product objects

CONSTRUCTOR:
  - Initialise empty _products dictionary

REQUIRED METHODS:

  add_product(name, category, price, quantity, min_stock)
    - Generate new product ID
    - Create Product object
    - Add to _products dictionary
    - Returns: product_id (str)
  
  remove_product(product_id)
    - Remove product from inventory
    - Returns: Removed Product object or None if not found
  
  get_product(product_id)
    - Returns: Product object or None if not found
  
  get_all_products()
    - Returns: List of all Product objects
  
  find_by_name(name)
    - Case-insensitive exact name match
    - Returns: product_id or None if not found
  
  search_by_name(search_term)
    - Case-insensitive partial match
    - Returns: List of matching Product objects
  
  search_by_category(category)
    - Case-insensitive exact category match
    - Returns: List of matching Product objects
  
  get_low_stock_products()
    - Returns: List of Product objects where is_low_stock() is True
  
  generate_category_report()
    - Returns: Dictionary with category statistics
    - For each category: product count and total value
  
  calculate_total_value()
    - Returns: Total value of all inventory
  
  _generate_id()
    - Private method (underscore prefix)
    - Generates next unique product ID
    - Returns: str
  
  __len__()
    - Returns: Number of products in inventory
    - Allows using len(inventory)

=============================================================================
COMMON MISTAKES TO AVOID
=============================================================================

1. Not using private attributes
   - Use underscore prefix for private attributes
   - Access through properties, not directly

2. Forgetting @property decorator
   - Properties need the @property decorator
   - Both getters and setters require decorators

3. Not validating in setters
   - Property setters must validate input
   - Raise appropriate errors for invalid values

4. Accessing private attributes directly
   - Don't bypass encapsulation by accessing private attributes directly
   - Always use properties for access

5. Forgetting @classmethod for from_dict
   - Class methods need the @classmethod decorator
   - First parameter should be cls, not self

6. Not calling setters in __init__
   - In constructor, assign to property names (not private attributes) 
     to trigger setter validation
   - This ensures validation happens during object creation
